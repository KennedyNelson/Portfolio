# Kennedy Nelson, portfolio

Static portfolio site served from `site/` (see `vercel.json`). No build step.

- `site/index.html`: the whole site (HTML, CSS and a little JS)
- `site/og.png`: share image used for link previews (LinkedIn, etc.)

Pushes to `main` deploy automatically on Vercel. Open `site/index.html` locally to preview.

The previous Next.js + Sanity version was removed from the tree and is available in git history (commit `5cdd846`).
